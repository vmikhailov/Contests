# Подробное объяснение алгоритма CountDigitOne

## Основная идея

Вместо того чтобы перебирать все числа от 1 до n и считать единицы в каждом (медленно),
мы считаем единицы **по разрядам** (быстро).

## Ключевая концепция

Для каждого разряда (единицы, десятки, сотни...) мы разбиваем число n на 3 части:
- **higher** - цифры СЛЕВА от текущего разряда
- **current** - цифра в текущем разряде
- **lower** - цифры СПРАВА от текущего разряда

## Пример разбиения числа 3141

### Разряд десятков (factor = 10):
```
n = 3141
     ║║
     ║└─ lower = 1 (справа)
     └── higher = 31 (слева)
    
current = 4 (сама цифра в разряде десятков)
```

### Как вычисляется:
```csharp
factor = 10
higher = 3141 / (10 * 10) = 3141 / 100 = 31
current = (3141 / 10) % 10 = 314 % 10 = 4
lower = 3141 % 10 = 1
```

## Три случая для подсчета единиц

### Случай 1: current == 0
Пример: n = 3041, factor = 10 (разряд десятков)
- higher = 30, current = 4 → 0, lower = 1

Единица в разряде десятков встречается только в числах вида XX10-XX19:
- 0010-0019 (10 чисел)
- 0110-0119 (10 чисел)
- ...
- 3010-3019 (10 чисел)

Всего: **higher × factor = 30 × 10 = 300**

### Случай 2: current == 1
Пример: n = 3141, factor = 10 (разряд десятков)
- higher = 31, current = 4 → 1, lower = 1

Единица встречается в:
1. Завершенных группах: 0010-0019, 0110-0119, ..., 3010-3019
   - Это **higher × factor = 31 × 10 = 310**
2. Текущей незавершенной группе: 3110-3141
   - Это **lower + 1 = 1 + 1 = 2**

Всего: **higher × factor + lower + 1 = 312**

### Случай 3: current > 1
Пример: n = 3241, factor = 10 (разряд десятков)
- higher = 32, current = 4, lower = 1

Единица встречается во всех завершенных группах (включая текущую):
- 0010-0019, 0110-0119, ..., 3210-3219

Всего: **(higher + 1) × factor = 33 × 10 = 330**

## Полный пример для n = 13

### Число 13 = "13"
Позиции:  десятки единицы
          1       3

### Итерация 1: factor = 1 (разряд единиц)
```
n = 13
    └─ смотрим на эту цифру

higher = 13 / 10 = 1          (слева от единиц: "1")
current = (13 / 1) % 10 = 3   (цифра единиц: "3")
lower = 13 % 1 = 0            (справа от единиц: ничего)
```

current = 3 > 1, поэтому:
```
count += (higher + 1) × factor = (1 + 1) × 1 = 2
```
Это единицы в разряде единиц в числах: **1, 11**

### Итерация 2: factor = 10 (разряд десятков)
```
n = 13
└─── смотрим на эту цифру

higher = 13 / 100 = 0         (слева от десятков: ничего)
current = (13 / 10) % 10 = 1  (цифра десятков: "1")
lower = 13 % 10 = 3           (справа от десятков: "3")
```

current = 1, поэтому:
```
count += higher × factor + lower + 1 = 0 × 10 + 3 + 1 = 4
```
Это единицы в разряде десятков в числах: **10, 11, 12, 13**

### Итерация 3: factor = 100
```
factor = 100 > n = 13, выходим из цикла
```

### Итого: count = 2 + 4 = 6

Проверка вручную:
- 1 → одна "1"
- 10 → одна "1"
- 11 → две "1"
- 12 → одна "1"
- 13 → одна "1"

Всего: 1 + 1 + 2 + 1 + 1 = **6 ✓**

## Сложность алгоритма

- **Время**: O(log n) - количество итераций = количество разрядов в числе
- **Память**: O(1) - используем только несколько переменных

Для n = 2,147,483,647 (максимальный int) нужно всего ~10 итераций!

## Почему используется long?

```csharp
long count = 0;
long factor = 1;
```

Потому что при больших n промежуточные вычисления могут превысить int:
- factor может стать очень большим (1, 10, 100, 1000, ...)
- Произведения higher × factor могут быть большими
