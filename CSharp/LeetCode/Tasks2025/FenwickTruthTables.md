# Таблицы истинности для Fenwick Tree

## Формулы
- `i + (i & -i)` — классическая формула перехода к следующему индексу при обновлении
- `i | (i + 1)` — альтернативная битовая формула

## Вывод
- Формулы `i + (i & -i)` и `i | (i + 1)` дают одинаковый результат только для некоторых значений i.
- В Fenwick Tree для перехода к следующему индексу корректно использовать только `i + (i & -i)`.
- Формула `i | (i + 1)` не всегда совпадает с классической формулой и может привести к ошибкам.

## Пример несовпадения
- Для i = 2: `i + (i & -i) = 4`, а `i | (i + 1) = 3`
- Для i = 3: `i + (i & -i) = 4`, а `i | (i + 1) = 7`
- Для i = 4: `i + (i & -i) = 8`, а `i | (i + 1) = 5`

**Используйте только классическую формулу для Fenwick Tree!**
